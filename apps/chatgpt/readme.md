# ChatGPT (Clone)

Minimalistic AI frontend

### Features (pdai)

* **Privacy**: fully private AI, hosted by redretep.
* **Free**: Explore curated playlists, top tracks, and albums.
* **No Sign-Up**: Quick search across artists, tracks, and podcasts.
* **Problem**: not as smart as regular AIs, due to high pricing, no file upload.

### Features (duck.ai)

* **Upload**: supports documents, code and photos.
* **Switch Models**: choose between GPT-5.4 nano, GPT-5.4 mini, Claude Haiku 4.5, Mistral Small 4, gpt-oss 120B and Gemma 4 31B.
* **Anonymous**: No information leaves your device.
* **No Sign-Up**: Uses YouTubes iFrame API and Data v3 API for playback.
